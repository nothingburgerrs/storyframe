# Storyframe

Offline Android app (Kotlin, Jetpack Compose, Room) for creating fictional Instagram-style profiles and exporting clean screenshots for mockups, moodboards and storytelling. No login, no backend.

## Build

```
./gradlew assembleDebug
```

Output: `app/build/outputs/apk/debug/app-debug.apk`. Requires JDK 17+ and the Android SDK (set `sdk.dir` in `local.properties`).
